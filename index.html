MAINTENANCE & SAFETY

Built around responsible reuse.

🧺 Clean filters

Inspect mesh screens, remove debris and check for blockages based on actual usage.

📟 Check sensors

Inspect sensor condition, calibration and readings. Retest when values are unusual.

🛡️ Separate plumbing

Use covered, labelled non-potable storage and separate plumbing to prevent cross-connections.

Proposed engineering flow

Wash basin → Collection pipe → Mesh filter → Settling chamber → Treatment filter → Validated treatment if needed → Monitoring → Covered storage → Non-potable reuse

This is a proposed concept. Filter media alone do not guarantee safe water. Prototype testing, suitable water-quality analysis and compliance with applicable requirements are needed before real-world deployment.
